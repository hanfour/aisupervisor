# Case Studies

This directory contains external projects used to demonstrate how AI Supervisor
can manage agentic software delivery from product planning through task
decomposition, implementation, review, verification, and approval.

These documents are not the product requirements for AI Supervisor itself. They
are examples of projects that AI Supervisor agents can plan and build. Customers
point AI Supervisor at their own repositories; the entries below exist as
teaching artifacts showing what the agentic workflow looks like end-to-end,
not as templates anyone is expected to copy.

## Examples

- [LINE Wi-Fi Ad SaaS](line-wifi-saas/README.md) — a LINE Login, LIFF, captive
  portal, and merchant marketing SaaS used as the first worked example of an
  end-to-end agentic delivery (PRD → task decomposition → implementation →
  review → verification → approval).
