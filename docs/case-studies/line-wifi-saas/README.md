# LINE Wi-Fi Ad SaaS Case Study

LINE Wi-Fi Ad SaaS is an external showcase project managed by AI Supervisor. It
is not the product direction of AI Supervisor itself.

The case study demonstrates the intended agentic delivery flow:

1. Product requirements are captured in a PRD.
2. AI Supervisor routes the PRD through human approval.
3. The approved PRD is decomposed into implementation tasks.
4. Workers implement tasks on isolated branches or worktrees.
5. Reviewers and council review the output.
6. Verification and human gates control what can be accepted.
